# ManagementMod

Управление игрой и миром. Minecraft 26.2, Java 25, Fabric (Loom). Id мода и пространство имён — `managementmod`, пакет `com.managementmod`. Бывший InstallerMod (переименован 2026-11-10, решение пользователя); в него перенесены версии мира и переключатель проверки аккаунтов из BuildMod. Карта проекта — `../CLAUDE.md`.

## Правила работы

- **После каждой правки:** собрать (`./gradlew jar --no-daemon -Dorg.gradle.jvmargs=-Xmx900m`) и положить `build/libs/managementmod-1.0.0.jar` (не `-sources`) в `~/.minecraft/mods/managementmod-1.0.0.jar` атомарно (`cp` во временный `.jar.tmp` и `mv -f`). Старый `installermod-*.jar` из mods убрать: иначе два мода с одним делом.
- Собирать **раньше** BuildMod и LevelMod: они компилируются против `../ManagementMod/build/libs/managementmod-1.0.0.jar`.
- Графического клиента у агента нет: UI и передачу файлов он проверить не может; сервер — `./gradlew runServer`.

## Что здесь

- `sync/`, `net/`, клиентские `SyncClient`, `SyncScreen`, `SyncSession` (бывший InstallerMod): сервер при входе игрока отдаёт манифест файлов из `mods/`, `resourcepacks/`, `shaderpacks/`, клиент спрашивает подтверждение и качает куски; имена файлов проверяются, пути нормализуются, SHA-256 сверяется. Раздаются только те моды, что загружены при старте (`onlyServeLoadedMods`). Режим **с подтверждением** — решение пользователя, автоматическую установку отвергли как небезопасную. Настройки — `config/managementmod.json` (прежний `installermod.json` переносится сам).
- `versions/`: версии мира («простой git», бывший `VcsServer` BuildMod). Снимок — все файлы мира, кроме самой истории, `session.lock`, `*.lock` и того, что другие моды объявили через `WorldVersions.skipTopLevel(имя)` (BuildMod: `buildmod_buildings`). Файлы по SHA-256 в `<мир>/managementmod_versions/objects/`, описание — `commits/<id>.json`, указатель — `head.json`. Откат: сервер двигает указатель, пишет `pending.json`, останавливается, на `SERVER_STOPPED` файлы мира заменяются версией (новых версий не создаёт). Папка прежнего имени `buildmod_vcs` переименовывается при первом открытии мира. **Только хост** (владелец мира; на выделенном сервере — операторы) и **только в творческом режиме** (в выживании окно закрыто, сервер отказывает). Клавиша V (`key.managementmod.versions`).
- **API для других модов:** `versions/WorldVersions` — `skipTopLevel(имя)`, `currentFiles(корень мира)` (путь → хеш текущей версии, `null` — версий нет), `read(корень, хеш)`. LevelMod читает версию только так; формат файлов истории знает один этот мод.
- `client/LanSettings`: на экране «Сетевая игра» (пауза) кнопка «Проверка аккаунтов: вкл/выкл» (`config/managementmod_lan.txt`, прежний `buildmod_lan.txt` переносится). При «выкл» и открытом для сети мире каждый тик клиента `server.setUsesAuthentication(false)` (как `online-mode=false`): **любой в сети может зайти под любым ником** — решение пользователя, «пока не важно»; побочное: хост по версиям определяется по нику.
